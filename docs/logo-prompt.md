# Linva — Logo 生成提示词（macOS 规范版）

> 供图像生成 Agent 使用。基于 Linva 的命名价值「梳理思绪、整理逻辑 / 逻辑线」。
> 核心图形围绕**「线」**：从杂乱思绪中理出一条清晰的逻辑线。
>
> 本版已按 **Apple HIG macOS App Icon 规范** 校准（见下「macOS 图标硬性规范」）。
>
> 生成后注意：图像模型给的是单张图，几何/边距/圆角未必精确符合规范——
> 若关键点不符，可交回主会话用 SVG 精确重画（图标最忌"看起来差但说不清差哪"）。

---

## macOS 图标硬性规范（Apple HIG + 官方尺寸，提示词已内化）

- **主画布**：1024×1024 正方形。
- **圆角方形（squircle）**：macOS 图标**自己画**圆角方形（系统不自动裁切，区别于 iOS）。
  内层内容容器 824×824，四边各留约 100px 安全边距。
- **圆角**：连续超椭圆（superellipse）曲率，1024 画布上等效半径约 185px。
- **投影**：柔和环境阴影 rgba(0,0,0,0.35~0.40)，Y 偏移 +4~8px，模糊 10~12px。
- **内容**：核心图形放在中心 824×824 内，四周留边距；缩到 16px 仍可辨识——
  避免过细线条、过密细节、过多层次。

## 主提示词（中文版，通用图像模型）

```
为「Linva」设计一个扁平极简的 macOS 应用图标。
Linva 是一个思维导图应用，核心价值是"把混乱的思绪梳理成清晰的逻辑"。

整体版式（严格遵循 macOS App Icon 规范）：
- 图标整体是一个圆角方形（squircle），四角圆润（连续超椭圆曲率，
  1024 画布上等效圆角半径约 185px）。
- 核心图形只占中央约 824×824 的区域，四周留出约 100px 的安全边距，
  图形不要触边。
- 图标带一层柔和的环境投影（轻微向下、轻微模糊）。
- 使用圆角方形背景。

图形设计：围绕"线"这个主题——
几条散乱、弯曲的细线（代表混乱的思绪），
从图标左侧或下方汇入，最终汇成一条笔直、清晰的主线
（代表整理后的逻辑），主线末端连接一个实心小圆点（代表思维节点）。
用圆头线条绘制，线条有粗细对比（主线比散线粗、更有力）。
视觉上传达"从乱到齐、从散到整"的转变。

用色：纯色圆角方形背景（建议系统蓝 #0A84FF 系），图形用白色。
画面中无文字、无字母、无渐变（背景与图形各为纯色）、无内描边。
扁平矢量风格，高对比度，构图居中。

尺寸：1024×1024，PNG，圆角方形完整绘制（含四角圆角与投影）。
```

## 备选方向（不满意可换着试）

| 方向 | 图形 | 追加描述 |
|---|---|---|
| **A. 乱线汇成主线**（主推） | 多条散乱弯线 → 汇成一条直线 + 末端圆点 | 见主提示词 |
| **B. 螺旋理顺** | 一条渐松的螺旋线，越往外越直，末端一个圆点 | 「一条从紧到松的螺旋线，越向外越平直，末端收成圆点」 |
| **C. 折叠展开** | 从一点分叉展开多条折线分支，末端各带圆点 | 「从一个中心点分叉展开多条折线分支，末端各带圆点」 |
| **D. 极简单线** | 仅一条粗圆头直线 + 末端圆点 | 「只有一条粗圆头直线，末端一个实心圆点」 |

## 变体调整词

| 调整 | 追加词 |
|---|---|
| 换背景色 | 白色圆角方形背景，蓝色线条（或指定任意色） |
| 强调"思维节点" | 圆点更突出、略大 |
| 更极简 | 只保留两条线（一乱一直） |
| 圆润友好 | 线条更圆润、拐角更平滑 |
| 无投影（部分风格） | 去掉投影，纯平 |

## 生成后自检清单（对照 macOS 规范）

- [ ] 1024×1024 正方形 PNG
- [ ] 四角是圆角方形（squircle），非直角、非纯圆
- [ ] 核心图形在中央 ~824×824 内，四周有边距，未触边
- [ ] 无文字、无字母、无多余装饰
- [ ] 缩到 16px 仍能看出"线 → 点"的图形
- [ ] 背景/图形各为纯色，无渐变

若任一项不符，交回主会话用 SVG 精确重画。
