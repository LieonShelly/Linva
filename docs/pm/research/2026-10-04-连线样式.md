# 外部调研：Node 连线样式（2026-10-04）

课题：为 Linva 的父-子结构连线（当前为**正交折线**，非直线）新增可切换的**连线样式**——曲线、大括号。探索起点：产品本人提出想支持「曲线 / 大括号」等样式，对齐竞品。

## 调研说明

- 本次以 `web_search` + `read` 抓取竞品官方文档为主；所有连线样式结论均来自官方页面（`[EVIDENCE]`）。
- 内部技术事实来自源码（`RadialLayout.edge()` / `LogicLayout` / `EdgeGeometry` / `MetalRenderer.edgeVertices`），非推断。

## 技术现状（内部事实，非推断）

- `EdgeGeometry`（`Layout/LayoutSnapshot.swift`）当前只含 `points: [CGPoint]`——一条 **3 段正交折线**（父中心横出 → 竖落 → 横进到子），**无贝塞尔控制点、无样式字段**。
- 形状在 **Layout 层**生成：`RadialLayout.edge(from:to:side:)`、`LogicLayout` 各产自己的 `EdgeGeometry`。
- 绘制在 **Metal 层**：`MetalRenderer.edgeVertices` 把 `points` 逐相邻点连成**直线段**描边（`zip(points, points.dropFirst())`）。
- 接缝：`LayoutPipeline.relayout(document:)` 按 `document.layout` 分派 `RadialLayout` / `LogicLayout`，两者同签名 `layout(document:measure:)`（`LayoutEngine` 协议）。

**结论**：当前连线既不是直线也不是曲线，是正交折线。要支持曲线/大括号 = 动 Layout（产曲线控制点）+ Render（曲线细分描边）两层；`LayoutSnapshot` 接缝需扩「样式 + 控制点」字段。

## 竞品连线样式全景（[EVIDENCE]）

| 竞品 | 连线样式能力 | 作用域 | 来源 |
|------|-------------|--------|------|
| **MindNode** | Branch Type 分 **Rounded（圆滑=曲线）** / **Angular（折角=折线）** 两种，可对各主节点分别设 | 按主节点（≈分支级） | https://www.mindnode.com/support/guides/mind-map-and-canvas-styling |
| **Miro（思维导图）** | 节点连线可选 **curved（曲线）或 straight（直线）**，并可改方向 | 全局 | https://help.miro.com/hc/en-us/articles/360017730753-Mind-map |
| **SimpleMind** | Relation path 样式：**curved / straight / rounded / angled** 四种，在样式表（style sheet）定义 | 全局（样式表） | https://simplemind.eu/faq/relation-path |
| **XMind** | 分支面板可设**连接的样式（含形状）**、支线宽度/端头；「括号图」是官方结构之一（`}` 形大括号连线） | 全局（主题/分支样式） | https://blog.csdn.net/weixin_45757101/article/details/132875485；https://xmind.app/features |
| **MindNoodle（开源）** | Connection Routing：**Bezier Curves（贝塞尔）/ Orthogonal Lines（正交）/ Straight Lines（直线）** | 全局 | https://github.com/anpinghuang/MindNoodle |

**要点**：
- 「父-子结构连线可换样式」是导图工具的**成熟度基线**，主流竞品全部支持，且几乎都是**全局一种**（除 MindNode 按主节点）——与产品本人选择的「全局一种」作用域一致。
- 「曲线 vs 折线」是竞品最常见的二分（MindNode Rounded/Angular、Miro curved/straight、MindNoodle Bezier/Orthogonal）。
- 「大括号（括号图）」在 XMind 是**独立结构**（`}` 形连线）；Linva 做成**全局连线样式**是它的轻量版——只换连线几何，不动布局，成本远低于新增一种结构。

## 用户吐槽点 / 需求线索（[EVIDENCE] + [ASSUMPTION]）

- `[EVIDENCE]` MindNode 明确把「Branch Type」列入**可读性**相关设置（圆滑 vs 折角影响观感与层级可读性）（https://www.mindnode.com/support/guides/mind-map-and-canvas-styling）。
- `[ASSUMPTION]`：辐射/折线连线在**层级深、分支密**时视觉生硬、不易一眼辨层级从属；曲线更顺滑专业（对齐成熟竞品观感），大括号更强调「总分/从属」语义（对齐 XMind 括号图）。
- `[ASSUMPTION]`：用户动机 = 视觉打磨 + 语义分层两者都要（内部访谈确认）。

## 候选 Idea 清单

| # | 候选 | 发现点（来源） | 对 Linva 价值 |
|---|------|---------------|--------------|
| E1 | **曲线 Curved** | 竞品标配（MindNode Rounded / Miro curved / SimpleMind curved / MindNoodle Bezier）[EVIDENCE] | 最主流、视觉最顺滑，对齐成熟度基线；实现 = Layout 发贝塞尔控制点 + Render 细分描边，工作量低 |
| E2 | **大括号 Brace** | XMind 括号图结构 `}` 形连线 [EVIDENCE] | 强表达总分/从属语义；做成全局样式（非新布局），成本可控 |
| E3 | 直线 Straight | Miro straight / SimpleMind straight [EVIDENCE] | 极简极客向；Linva 现状是正交折线，直线是另一种形态 |
| E4 | （对照）按分支/按节点设样式 | MindNode 按主节点 [EVIDENCE] | 灵活但复杂，与「全局一种」选择冲突，v1 不做 |

## 作用域 / 成功标准（内部访谈收敛）

- 作用域：**全局一种样式**（对齐竞品主流，贴合单人 v1）。
- v1 样式集：**曲线 + 大括号 + 正交折线（现状保留为默认）**。
- 成功标准：工具栏/菜单**一键切换**，整图即时重绘、**无损**（选中/折叠/相机不动）。持久化 / Undo **明确不进 v1**（产品本人拍板最低标准）。
