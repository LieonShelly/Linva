# YMind — App 命名决策

> 本文档记录 YMind 对外显示名的命名决策与商标查证，供后续品牌/商标工作引用。

## 决策结论

- **工程名 / 代码命名体系**：保留 `YMindApp`、`.ymind`、Y 前缀内部命名（不变）。
- **对外显示名**：**Linva**（读作 /ˈlɪnvə/，林-瓦）。
- **图标**：待定（与命名解耦，可基于 Linva 的价值重新设计，不依赖 Y 字母）。

## 命名推导

**产品核心价值**：把混乱的思绪梳理成清晰的逻辑。

**命名约束**（演化过程）：
1. 避开 X 开头（XMind）、避开已占用的脑图品牌（MindNode / iThoughts / MindMeister / Freeform / MarginNote / 亿图等）。
2. 用自创词（拼装词），而非现成单词——商标最安全、辨识度最高、好记顺口。
3. 词义呼应"梳理思绪 / 整理逻辑 / 逻辑线"。

**候选演化**：
- `YMind` → 与 XMind 一字之差，同类产品，商标混淆风险高，弃。
- `Linera` → 与 **Linear**（知名项目管理工具）、**Liner**（韩 AI 生产力工具）仅一字母差，同属生产力软件品类，撞车面广，弃。
- **`Linva`** → 查证干净，保留 Lin-（逻辑线）联想，词尾彻底脱开 Linear/Liner。

## Linva 商标查证（2026-10，公开信息）

| 发现 | 风险 |
|---|---|
| linva.design（独立设计师接单站，设计服务） | 低——设计服务个人站，非生产力软件产品，品类不同 |
| Linova（印度金融科技公司，拼写 -nova） | 低——拼写不同，金融品类 |
| Linear / Liner / Lin / LINEA / LANERA / LIVANOVA / LINEAVA | 无撞车——拼写差异明显 |

**结论**：Linva 未发现同拼且同属"生产力/思维软件"的强势商标，可用。

**注意**：以上为公开信息初步查证，非正式法律意见。正式发布/上架前，建议在中国商标局（CNIPA）与 USPTO 各做一次精确商标检索，并视需要申请注册（第 9 类软件、第 42 类在线服务）。
