# YMind — Component Spec: Context Menu（右键菜单）

> **现状缺失（HIG Rule 1.4 / 6.2 强制）**：所有交互元素必须右键可操作。本规格为新增项。
> SwiftUI `.contextMenu` 或 AppKit `NSMenu`；内容 = 菜单栏动作子集 + 元素专属动作。

---

## 1. 触发

- 节点上右键 → 节点菜单。
- 画布空白右键 → 画布菜单。
- 多选时右键 → 对**整个选中集**操作。

---

## 2. 节点右键菜单

| 项 | 快捷键 | 作用域 |
|---|---|---|
| 添加子主题 | Tab | 该节点/选中集 |
| 添加同级主题 | Return | 该节点 |
| 编辑… | Enter | 该节点 |
| ── 分隔 ── | | |
| 剪切 | ⌘X | 选中集 |
| 复制 | ⌘C | 选中集 |
| 粘贴 | ⌘V | 作为该节点子节点 |
| ── 分隔 ── | | |
| 移到左侧 | ⌘← | 选中集（仅一级） |
| 移到右侧 | ⌘→ | 选中集（仅一级） |
| 折叠/展开 | — | 该节点 |
| ── 分隔 ── | | |
| 填色子菜单 | — | 选中集 |
| 删除 | Delete（危险） | 选中集 |

> 与菜单栏动作**同一命令**（复用 `DocumentCommands` 逻辑），不另写一套，防「两处行为漂移」。

---

## 3. 空白右键菜单

| 项 |
|---|
| 适应画布 |
| 重置视图 |
| ── 分隔 ── |
| 粘贴（若剪贴板有） |
| 全选 ⌘A |

---

## 4. 行为细则

1. 菜单项**动态使能**：无选中时剪切/复制/删除禁用；根节点「移到侧」禁用。
2. 多选时标题反映数量（如「删除 3 项」），对齐 HIG Rule 1.3。
3. 危险项（删除）在菜单内用危险样式/红字。
4. Esc 关闭菜单；菜单项都带菜单栏同款快捷键提示。

---

## 5. 无障碍

- 菜单是系统原生控件，自动支持 VoiceOver / 键盘导航。
- 所有项有明确 label（不用纯图标）。
