# YMind 组件规格 — 右键菜单（Context Menu）

> 层级：**SwiftUI 壳**（`.contextMenu`）。现状工具条收敛后，剪切/复制/粘贴/改侧/导出等低频命令移入菜单栏 + 右键菜单。右键菜单是 Mac 交互的核心（HIG 6.2：**每个可交互元素都必须响应右键**）。本组件为**新增**（当前 Shell 无 `.contextMenu`，只有 `MainToolbar` 与 `DocumentCommands` 菜单栏）。

---

## 1. 挂载点与内容

| 目标 | 右键内容（上下文相关） |
|------|----------------------|
| **节点**（含多选） | 添加子主题（Tab）、添加同级主题（Return）、分隔线、剪切（⌘X）、复制（⌘C）、粘贴为主题子节点（⌘V）、分隔线、移到左侧（⌘←）、移到右侧（⌘→）、填色 ▸（子菜单 5 色 + 清除）、分隔线、删除（Delete, role destructive） |
| **中心主题** | 添加子主题、粘贴、填色 ▸、分隔线、删除（根不可删 → 禁用） |
| **空白画布** | 添加子主题（挂根）、粘贴、分隔线、适应画布 |
| **选中图片块** | 替换图片…、移除图片（⌫） |
| **折叠子树节点** | + 展开（空格） |

> 规则：右键菜单 = 菜单栏命令的**相关子集** + 元素特有动作（HIG 1.4）。删除项 `role: .destructive`。

---

## 2. 状态表

| 元素 | 默认 | hover | disabled |
|------|------|-------|----------|
| 普通项 | `text.primary` | 高亮 | `text.secondary` |
| 破坏性项（删除） | `sem.color.danger` 文字 | 高亮 | opacity 0.4 |
| 分隔线 | `separator` | — | — |
| 子菜单（填色 ▸） | 箭头 + 色点 | 高亮 | 无选中禁用 |
| 快捷键 | 右侧 `monospaced` | 同 | — |

- 系统菜单外观（`.contextMenu` 原生）；无选中时禁用对应项（如剪切/删除）。
- 色点子菜单色点即 `prim.color.fill.*`，复用 `NodeFillStyle.swatch`。

---

## 3. 行为

| 事件 | 行为 |
|------|------|
| 右键节点 | 选中该节点（若未选中），显示上下文菜单 |
| 操作 | 全部走 `CommandBus`（`session.commandBus.execute`）或现有会话用例，Undo 一致 |
| 关闭 | Esc / 点击外部 |

---

## 4. 无障碍 / 合规

- 全部菜单项有文字标签（无纯图标）。
- 与菜单栏命令共享同一快捷键，状态同步（`canDelete`/`canCopy`/`canPaste`/`canSetSide` 现状已算好）。
- 键盘：菜单栏 + 快捷键是主通道，右键菜单是加速（HIG 1.6）。
