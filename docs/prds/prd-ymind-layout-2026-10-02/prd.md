# PRD：YMind — 新增布局类型（逻辑图·总分树 + 布局切换器）

## 0. 文档目的

本文描述布局能力增量：**同一棵树在「辐射」与「逻辑图（总分树）」两种布局间无损、瞬时切换**。产品本人访谈确认最痛点场景为**总分归纳（读书笔记 / 知识体系）**——辐射布局读序不自然、结构语义弱；决策为「做」（ICE 12.8），排期**推荐紧随 1.0 之后**（见 §9.1，待拍板）。

- **上游：** [v1 PRD](../prd-ymind-2026-09-24/prd.md)
- **需求真源：** [机会卡片](../../pm/opportunities/2026-10-02-新增布局类型.md)（FR 编号 L1…L5 与卡片一致）
- **体验真源：** `prototype/layout-switcher.html`（布局切换器 / 逻辑图形态 / 边界与非目标）
- **明确不在本增量：** 主题/配色列表；矩阵/鱼骨/时间轴/自由画布；多结构混用；切换动画；大纲视图。

文档语言：中文优先。

## 1. 愿景与要完成的工作

YMind 目前只有辐射布局——根在中心、分支左右对称展开，擅长「发散收集」。但用户在读书笔记、知识体系整理时需要**总分归纳**的表达：结论先行、层层细分，像书的目录、像金字塔——「谁概括谁」一目了然。

核心洞察：**同一份数据，需要不同的读法**。发散阶段用辐射，归纳阶段换总分。切换必须无损（不重建文档、不丢选中/折叠/相机）、瞬时（一键重排）。

三条主链路：
- **选布局：** 工具栏「布局」菜单，辐射 ↔ 逻辑图，一键切换即重排；切换入命令栈（⌘Z 可撤销）。
- **换形态：** 逻辑图 = 根在最左、层级向右层层展开、总分树形态；L 形正交边；折叠 toggle 在节点右侧。
- **记得住：** 布局随文档持久化（.ymind v5），重新打开保持；切回辐射不丢左右 side 数据。

成功标准（SM 见 §6 语境）：阿哲能把读书笔记一键切成总分树形态交付，布局稳定不丢状态，打开文件保持上次布局。

## 2. 关键用户旅程

**UJ-L1. 阿哲把一篇读书笔记整理成总分结构。**

1. 打开《认知觉醒》笔记导图（辐射）；2. 工具栏 → 布局 → 逻辑图；3. 全图立即重排为总分树：根在最左，章节向右、要点再向右；4. 折叠某章节点看总览（toggle 在右侧）；5. 觉得还是发散读法好，⌘Z 撤销切回辐射——选中与相机保持。

**UJ-L2. 阿哲隔天再打开这份笔记。**

1. 打开 `.ymind` 文件；2. 画布直接以**上次的逻辑图布局**呈现（无需重切）；3. 布局与内容一起保存。

**UJ-L3. 阿哲在逻辑图下整理时想调整左右分组。**

1. 试图用 ⌘←/⌘→ 设侧；2. 操作**置灰**（逻辑图无左右语义）；3. 切回辐射布局，原左右分组完整保留。

## 3. 术语表（增量）

| 术语 | 定义 |
|------|------|
| **布局（Layout）** | 同一棵节点树在画布上的空间排布方式。本文档语境 = 文档属性（随 `.ymind` 持久化），非会话/视图态。 |
| **逻辑图 / 总分树** | 新增布局：根在最左，子节点垂直排列在父节点右侧、逐层向右展开；读序从左到右、从总到分（目录/金字塔式）。 |
| **布局切换器** | 工具栏「布局」菜单（辐射 ↔ 逻辑图），切换即 `relayout()`；切换入命令栈可 Undo/Redo。 |
| **side 语义** | 辐射布局特有的根下一层 left/right 分组（`Node.side`）。逻辑图无左右之分：frame.side 统一处理，模型层数据保留。 |

## 4. 功能需求

### 4.1 布局模型与持久化

**描述：** 布局是文档属性，随 `.ymind` 持久化；老文件缺省为辐射布局。实现 UJ-L2。

**功能需求：**

#### FR-L1：LayoutKind 字段与 Codec v5

`MindMapDocument` 增 `layout` 字段（enum `LayoutKind`：`.radial` / `.logic`，Codable）；Codec 升 v5 并迁移：v4 文件缺省 `.radial`，零拒绝。

**Consequences（可测）：**
- `MindMapDocument` 增 `layout: LayoutKind`（缺省 `.radial`）；`LayoutKind` 为 `Codable, Equatable, Sendable`。
- `MindMapDocument.currentVersion` 升 **5**；`YMindCodec` 内置 v4→v5 迁移：缺省 `layout = .radial`，旧文件零拒绝打开（同 `fill`/`image` 先例）。
- `DocumentSession` 暴露 `layout`（`@Published` 或等价），供工具栏与渲染读取。
- 布局切换**入命令栈**（`setLayout` 命令，仿 `setFill`），Undo/Redo 均触发重排。
- `sanitize` 不变（布局不改变节点约束；`side` 消毒规则保持）。

**Out of Scope：** 布局与会话态分离（不做「仅本次会话的临时布局」）；布局级主题/配色（独立课题）。

### 4.2 逻辑图布局

**描述：** 新写 `LogicLayout.layout(document:measure:) -> LayoutSnapshot`——单向总分树，与 `RadialLayout` 结构同构。实现 UJ-L1。

**功能需求：**

#### FR-L2：LogicLayout 总分树排布

逻辑图把树排成总分形态：根在最左，每一层子节点垂直排列在父节点右侧，递归向右展开；`NodeFrame` / `EdgeGeometry` / `branchToggles` 按逻辑图形态生成。

**Consequences（可测）：**
- 复用 `RadialLayout` 的 `subtreeHeight` 递归测高结构与 `TextMeasure` / `centeredBlocks` / `collectPayloads`（图片节点照常收集 `imagePayloads`）。
- `NodeFrame.side`：逻辑图下统一 `.right`（或忽略）；模型层 `Node.side` 数据**不修改**，切回辐射布局左右分组完整。
- 边为 **L 形正交曲线**（先水平后垂直，总→分读序），与辐射对称曲线区分。
- 折叠 toggle 统一在**节点右侧**（无左右之分）；折叠行为与辐射一致（后代不占空间）。
- 命中 / 选中 / 拖拽移动 / 插入线全部基于 `NodeFrame`，自动兼容，无需新逻辑。
- 根折叠（整图折叠）时输出与辐射一致的退化快照。

**Out of Scope：** 不同分支不同结构（多结构混用，v1 不做）；逻辑图内的自由主题/独立排布。

### 4.3 布局切换器

**描述：** 工具栏「布局」菜单一键切换，切换入命令栈。实现 UJ-L1 / UJ-L3。

**功能需求：**

#### FR-L3：布局菜单与切换命令

工具栏新增「布局」菜单（辐射 / 逻辑图）；切换调用 `setLayout` 命令 → `relayout()`；Undo/Redo 均可往返；切换后选中与相机保持。

**Consequences（可测）：**
- `MainToolbar`（SwiftUI 壳层）增布局菜单/分段控件，当前布局高亮。
- 新增命令 `setLayout(kind: LayoutKind)` 入 `MindMapCommand`；执行时 `commitEditingIfNeeded()` → 改 `model.document.layout` → `relayout()`（与 `setFill` 同模式）。
- 切换后选中节点集合、折叠状态、相机（center/scale）保持不变。
- 布局菜单在无选中/多选时可用（布局是文档属性，与选中无关）。

**Out of Scope：** 布局切换动画（瞬时切换即可）；布局快捷键默认绑定（可选 ⌥L，实现时定）。

### 4.4 交互兼容与 side 降级

**描述：** 逻辑图下与现有交互全部兼容；左右 side 操作降级置灰，避免语义混乱。实现 UJ-L3。

**功能需求：**

#### FR-L4：side 操作在逻辑图下降级

逻辑图布局下，「设为左/右侧」（⌘←/⌘→、侧向拖放）**置灰禁用**；切回辐射恢复。

**Consequences（可测）：**
- `DocumentSession.canSetSide` / 侧向拖放意图在 `.logic` 布局下返回 false（UI 置灰）。
- 禁用只是 UI 层——命令层 `setSide` 不新增约束（避免破坏 Undo 历史中的旧 side 操作回放）。
- 模型层 `Node.side` 在逻辑图下**不被修改也不被清除**；`sanitize` 的 side 消毒规则不变。
- 拖拽搬移节点（父子关系）在逻辑图下照常工作；插入线、插入兄弟照常。

**Out of Scope：** 逻辑图下新增「上/下」方向的侧语义（v1 不做，避免扩大 side 模型）。

### 4.5 导出

**描述：** 导出按当前布局渲染；布局不进入 Markdown 结构。实现 UJ-L1 收尾。

**功能需求：**

#### FR-L5：导出按当前布局

PNG 导出（全展开）按当前布局离屏渲染；Markdown 结构导出不表达布局；`.ymind` 持久化布局字段（FR-L1）。

**Consequences（可测）：**
- PNG 导出复用 `MetalRenderer` 的 `LayoutSnapshot` 管线——`relayout()` 产出哪张快照就渲染哪张，自动按当前布局。
- Markdown 导出（既有 FR-E2）输出树结构，与布局无关，不新增内容。
- `.ymind` 读写包含 `layout`（FR-L1 迁移兜底）。

**Out of Scope：** 布局级导出模板（如按总分树固定宽度分页）；PDF 分页按布局特化（随既有 PDF 导出走，不特化）。

## 5. 非目标（明确不做）

- 主题 / 配色列表（用户提及的「主题列表」是独立课题，布局与主题解耦）。
- 矩阵图 / 鱼骨图 / 时间轴 / 自由画布（机会卡片 §6 候选对比后搁置）。
- 多结构混用（同图不同分支不同结构——XMind 式高级能力，v1 不做）。
- 布局切换动画过渡（瞬时切换即可）。
- 逻辑图下新增上/下方向侧语义。
- 大纲视图（backlog 已搁置，与布局正交）。
