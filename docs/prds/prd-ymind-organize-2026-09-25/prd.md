# PRD：YMind — 整理效率（多选与画布折叠）

## 0. 文档目的

本文档描述 **v1 之后、以「整理效率」为主线** 的产品增量：多选、框选、批量删除，以及折叠/展开从工具条迁到画布连线分叉处。

- **上游：** [v1 PRD](../prd-ymind-2026-09-24/prd.md)（建树、单选时代的 FR-1～16 仍有效；本文件修订其中与选中、折叠入口冲突的条款）
- **体验真源：** `prototype/`（搬枝增量见标签 Move；多选能力仍在同一原型中）
- **明确不在本增量：** 拖拽改层级 / 改顺序、复制剪切粘贴（见 [搬枝 PRD](../prd-ymind-move-2026-09-25/prd.md)）、第二种布局、导出（另案）

文档语言：中文优先。

---

## 1. 愿景与要完成的工作

v1 已证明「中心辐射 + 快速建树 + 流畅画布」成立。下一痛点是：**大图建成后难整理**——一次只能操作一个节点，折叠入口在工具条上也不贴合「看图」心智。

本增量目标：用户能在画布上**一次选中多枝**，批量删除或（借助键盘）批量折叠；折叠/展开**就在父子连线的分叉处**完成，工具条不再承载折叠。

---

## 2. 关键用户旅程

**UJ-O1. 阿哲框选右侧一枝，批量删掉过时议题。**

1. 在空白处拖出矩形，框住多个节点；工具条出现「已选 N」，「子主题 / 同级」禁用，「删除」可用。  
2. 按 ⌫ 或点删除；非中心主题的选中节点（含子树）移除；若选中含中心主题则中心主题保留。  
3. 删除后选中落在合理父节点（或清空后再单击）。

**UJ-O2. 阿哲用 ⌘ 点与 Shift 连选，整理同级议题。**

1. 单击某节点作为锚点；⌘ 单击加减选；在同父兄弟上 Shift 单击连选区间。  
2. 多选高亮清晰；锚点在多选时有可辨识提示（原型：虚线描边）。

**UJ-O3. 阿哲在分叉处折叠「技术方案」子树。**

1. 有子节点的主题在朝向子树的连线出口显示控件。  
2. 展开态显示 **＋**，点击后折叠；折叠态显示 **−N**（N 为隐藏后代数），点击后展开。  
3. 工具条无「折叠 / 展开」按钮。

---

## 3. 术语表（增量）

沿用 v1 术语，并增补 / 修订：

| 术语 | 定义 |
|------|------|
| **选中集（Selection）** | 当前选中的节点 ID 集合；可为 0、1 或多个。 |
| **锚点（Selection Anchor）** | 用于 Shift 连选的基准节点；普通单击或 ⌘ 加入选中时更新。 |
| **多选（Multi-select）** | 选中集大小 ≥ 2。 |
| **框选（Marquee）** | 在画布空白拖出矩形，选中与矩形相交的可见节点。 |
| **分叉控件（Branch Toggle）** | 位于节点朝向子树一侧、连线出口附近的折叠/展开控件；符号与隐藏数量合一展示。 |
| **严格工具条模式** | 多选时禁用「子主题 / 同级」；折叠不在工具条；删除对选中集中可删节点整组生效。 |

**修订 v1「折叠」展示：** 不再使用节点角标作为主入口；隐藏数量与分叉控件上的 **−N** 合一。

**修订 v1「选中」：** 不再限制为单节点（见 FR-O9 起）。

## 4. 功能需求

### 4.1 多选手势

#### FR-O1：单击单选

在非编辑态，单击节点：选中集变为仅该节点，并设为锚点。

**可验证结果：** 仅该节点高亮；工具条按单选规则启用。

#### FR-O2：⌘ / Ctrl 单击加减选

⌘（Mac）或 Ctrl 单击：若已在选中集则移除，否则加入；加入时更新锚点。

**可验证结果：** 可形成不连续多选；减选至 0 个时无选中。

#### FR-O3：Shift 同父连选

在已有锚点时，Shift 单击另一节点：若二者**同一父节点**，选中集变为该父下从锚点到目标（含端点）的连续兄弟；若不同父，退化为单选目标节点。

**可验证结果：** 同级兄弟可一次选中区间；跨枝 Shift 不产生错误跨父选中。

#### FR-O4：框选

在画布**空白**按下并拖动：绘制选框；松开时选中与选框相交的可见节点。  
⌘/Ctrl + 框选：在现有选中集上**追加**相交节点。  
按下后几乎无移动（阈值内）：视为点击空白 → **清空选中**（追加模式下不强制清空）。

**可验证结果：** 框选可一次选中多枝；点空白可清空。

#### FR-O5：平移与框选分工

- **默认空白拖：** 框选（本增量）  
- **空格键按住 + 拖空白：** 平移画布  
- 滚轮缩放、适应画布：行为同 v1（FR-12、FR-13）

**可验证结果：** 用户能完成框选且仍能平移浏览大图。  
`[ASSUMPTION: 原生实现可保持该分工；若可用性测试强烈偏好「默认拖=平移」，可改为 ⌥ 拖框选，但须改原型并修订本条。]`

#### FR-O6：辅助选中快捷键

- **Esc：** 清空选中  
- **⌘A：** 选中当前布局中全部可见节点（折叠隐藏的不可见节点不选）

**可验证结果：** 与手势选中状态一致。

---

### 4.2 多选下的工具条与批量删除

#### FR-O7：严格工具条模式

| 选中状态 | 子主题 | 同级 | 删除 |
|----------|--------|------|------|
| 无选中 | 禁用 | 禁用 | 禁用 |
| 单选 · 中心主题 | 可用 | 禁用 | 禁用 |
| 单选 · 非中心 | 可用 | 可用 | 可用 |
| **多选** | **禁用** | **禁用** | 对选中集中非中心主题可用 |

多选时工具条展示 **「已选 N」**（N≥2）。

**可验证结果：** 多选时无法通过工具条/Tab/Enter 误增节点；删除仍可用。

本增量**不在工具条提供折叠**（见 §4.3）；修订 v1 FR-2。

#### FR-O8：批量删除

对选中集中所有**非中心主题**节点删除其整棵子树。若父子同在选中集，只删除较顶层选中即可（子随父去）。中心主题不可删，即使被选中也跳过。

删除后：优先选中被删顶层节点的父（若仍存在），否则清空或不选。

**可验证结果：** ⌫ / Delete / 工具条删除对多选整组生效；中心主题始终保留。

**Undo：** 原生实现中，一次批量删除应为命令栈上的**一步**（可整体撤销）。原型可不做 Undo。

---

### 4.3 分叉处折叠 / 展开

#### FR-O9：分叉控件位置

凡**有子节点**的可见节点，在朝向子树一侧的连线出口附近展示分叉控件。  
中心主题若左右均有子树（或整树折叠后仍需提供入口），左右出口可各有一个控件，均作用于中心主题自身的折叠状态。

**可验证结果：** 无需打开工具条即可折叠/展开；无子节点的节点无控件。

#### FR-O10：符号与数量合一（产品极性）

| 节点状态 | 控件展示 | 点击结果 |
|----------|----------|----------|
| 已展开（子可见） | **＋** | 折叠该节点全部后代 |
| 已折叠 | **−N**（N=隐藏后代数；若为 0 可仅显示 −） | 展开 |

**可验证结果：** 与已认可原型一致；用户不依赖工具条文案切换。  
`[NOTE: 该极性与部分竞品「＋=展开」相反，以本产品拍板为准。]`

#### FR-O11：折叠语义（与 v1 一致）

折叠后后代不可见、不占布局；展开后恢复。父节点折叠时，对其「添加子主题」仍应自动展开（继承 v1 FR-4）。

#### FR-O12：可选键盘批量折叠

非编辑态，`/` 或 `⌘.`：对**当前选中集**中所有「有子节点」的节点统一折叠或展开（若存在任一展开则全部折叠，否则全部展开）。

**可验证结果：** 多选时可不逐个点分叉控件。  
本条为增强，不替代 FR-O9/O10。

---

### 4.4 与编辑态的关系

#### FR-O13：编辑态排他

双击进入编辑时，选中集收敛为该节点；编辑态不响应多选快捷键与框选（同 v1：编辑态不误触全局快捷键）。

## 5. 非目标（本增量）

- 拖拽改父级 / 改同级顺序  
- 复制 / 剪切 / 粘贴子树

- 按「侧」分别折叠中心主题左右子树（左右控件共享同一 `collapsed`）  
- 多文档、导出、样式系统

## 7. 成功指标

- **SM-O1：** 用户能仅用框选 + ⌫ 删掉 ≥3 个分散节点，无需逐个删除。  
- **SM-O2：** 用户能仅用分叉控件完成折叠/展开，且说得出「＋折叠、−展开」。  
- **SM-O3：** 多选时不会误触发 Tab/Enter 增节点（严格工具条）。  

反向：不以「手势种类接近 XMind」为成功；本增量不顺带做拖拽。

## 8. 开放问题

1. 默认空白拖=框选、空格拖=平移，在原生触控板用户中是否需要可配置？  
2. Shift 连选是否扩展为「同侧可见路径上的连续节点」（不仅同父兄弟）？当前：**仅同父**。  
3. 批量折叠是否需要工具条入口？当前：**不要**；仅分叉控件 + 可选 `/`。  
4. 多选时分叉控件点击：只作用于被点节点，还是作用于选中集？当前原型：**只作用于被点节点**；批量靠 `/`。
