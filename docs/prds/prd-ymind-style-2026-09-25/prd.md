# PRD：YMind — 节点轻填色

## 0. 文档目的

本文档描述「表达与扫视」的最小样式增量：为节点提供**少量预设填色**，便于分类辨识。明确不做主题商店或富文本样式系统。

- **上游：** [v1 PRD](../prd-ymind-2026-09-24/prd.md)
- **体验真源：** `prototype/`（标签 Style）
- **明确不在本增量：** 自定义取色器、渐变、字体档、边框样式包、深色模式专档（可随系统外观另案）、导出时色差精调

文档语言：中文优先。

---

## 1. 愿景与要完成的工作

结构操作（整理 / 搬枝 / 改侧 / 搜索）已齐；用户仍缺**低成本视觉分类**。本增量用工具条上的色点，对选中节点（含多选、含中心主题）套用或清除预设填色。

---

## 2. 关键用户旅程

**UJ-C1. 阿哲给「问题定义」整枝刷成鼠尾草色。**

1. 选中该节点（或框选多个）；点工具条鼠尾草色点。  
2. 节点背景与边框变为该预设；色点呈选中态。  
3. 点「默认」色点（带清除示意）恢复无填色。

---

## 3. 术语表（增量）

| 术语 | 定义 |
|------|------|
| **填色（fill）** | 节点上的可选预设 token；`null` 表示默认外观。 |
| **色点（swatch）** | 工具条上的圆形色样控件；含「默认」清除项。 |

---

## 4. 功能需求

#### FR-C1：预设集合

固定 **5** 个具名预设（实现可用 token）：`sage` / `sky` / `sand` / `rose` / `lilac`。  
另有 **默认（无填色）**。不可自定义 RGB。

#### FR-C2：工具条入口

工具条提供色点组；无选中时全部禁用。  
单选时，当前 fill 对应色点为激活态；多选若 fill 不一致则无激活态。

#### FR-C3：作用范围

对当前选中集**每一个**节点写入同一 fill（含中心主题）。  
复制粘贴须保留 fill（剪贴板快照含 fill）。

#### FR-C4：视觉

普通节点：浅底 + 协调边框。  
中心主题：同 token 的深色变体，保持字色可读。  
选中 / 搜索命中等高亮仍叠加在填色之上。

#### FR-C5：非目标边界

不做：字号档、粗体、主题包切换、按侧自动配色、从图片取色。

---

## 5. 验收要点

| # | 场景 | 期望 |
|---|------|------|
| 1 | 单选点色 | 节点变色，色点激活 |
| 2 | 多选点色 | 全部同色 |
| 3 | 点默认 | 恢复无填色 |
| 4 | 无选中 | 色点禁用 |
| 5 | 复制粘贴 | 副本保留填色 |
| 6 | 中心主题上色 | 深色变体可读 |

---

## 6. 原型对照

| 原型 | 需求 |
|------|------|
| `.fill-swatches` 色点 | FR-C1、C2 |
| `node.fill` + `data-fill` | FR-C3、C4 |
| `cloneSubtree` 带 fill | FR-C3 |
| 标签 Style | 体验真源 |

路径：`prototype/`。

## 7. 持久化备注

原生 `.ymind` 应增加可选字段 `fill`（string token | 省略）；未知 token 读入时视为默认。
