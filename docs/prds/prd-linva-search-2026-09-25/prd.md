# PRD：Linva — 搜索定位

## 0. 文档目的

本文档描述「日常回访」增量：**在整棵主题树中按文案查找节点，并跳转选中**（含折叠枝内命中）。

- **上游：** [v1 PRD](../prd-linva-2026-09-24/prd.md)；整理 / 搬枝 / 同级排序已具备
- **体验真源：** `prototype/`（标签 Search）
- **明确不在本增量：** 正则 / 全词匹配选项、替换文案、按样式或侧过滤、导出

文档语言：中文优先。

---

## 1. 愿景与要完成的工作

大图整理手势已齐；下一痛点是**回访时找不到枝**。本增量让用户用熟悉的 ⌘F 打开搜索，在含折叠子树的整棵树上匹配文案，并自动展开路径、对准画布、选中命中项。

---

## 2. 关键用户旅程

**UJ-S1. 阿哲在折叠的「技术方案」下找「命中测试」。**

1. ⌘F 打开顶栏浮层；输入「命中」。  
2. 计数显示命中数；当前项高亮；折叠祖先自动展开；相机平移到该节点。  
3. Enter / ↓ 下一项，⇧Enter / ↑ 上一项；Esc 关闭浮层（选中可保留）。

---

## 3. 术语表（增量）

| 术语 | 定义 |
|------|------|
| **搜索浮层** | ⌘F 唤起的非常驻顶栏：输入框、计数、上/下一项、关闭。 |
| **整树匹配** | 对文档中全部节点文案检索，不限于当前可见帧。 |
| **展开路径** | 命中若位于折叠子树内，将其全部祖先设为展开后再布局。 |
| **当前命中** | 匹配列表中的焦点项；画布上另有搜索高亮样式。 |

---

## 4. 功能需求

#### FR-S1：打开与关闭

- ⌘F（Windows/Linux 可用 Ctrl+F）打开浮层并聚焦输入框；已打开则再次 ⌘F 聚焦并全选查询。  
- Esc 或关闭按钮关闭浮层。  
- **适应画布**仍由工具条承担；不再占用 ⌘F。

#### FR-S2：匹配规则

- 对节点 `text` 做**不区分大小写的子串**包含匹配。  
- 遍历整棵树（含折叠枝内节点）；空查询无匹配。  
- 匹配顺序：深度优先先序（稳定，便于上/下一项）。

#### FR-S3：揭示与跳转

命中当前项时：

1. 展开通往该节点的全部祖先；  
2. 选中集变为仅该节点；  
3. 重新布局后，相机平移使该节点居中（保持当前缩放）；  
4. 节点呈现「搜索命中」高亮（可与普通选中并存或叠加区分）。

#### FR-S4：上一项 / 下一项

- 浮层按钮与 Enter（下一项）/ ⇧Enter（上一项）；可选 ⌘G / ⇧⌘G。  
- 在匹配列表内循环。  
- 查询变更时重新计算列表；尽量停留在仍匹配的同一节点，否则跳到第一项。

#### FR-S5：与编辑态关系

编辑节点文案时，⌘F 先提交编辑再打开搜索。搜索输入框聚焦时，不触发 Tab/Enter 增删同级等画布快捷键。

## 6. 验收要点

| # | 场景 | 期望 |
|---|------|------|
| 1 | ⌘F | 浮层出现，输入框聚焦 |
| 2 | 匹配折叠内节点 | 祖先展开，节点可见并居中选中 |
| 3 | 多项 Enter | 循环下一项 |
