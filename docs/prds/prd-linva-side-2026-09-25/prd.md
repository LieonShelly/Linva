# PRD：Linva — 手动改侧（左 / 右）

## 0. 文档目的

本文档描述中心辐射布局下的表达增量：**用户显式指定一级枝在中心主题的左侧或右侧**，不再只依赖自动均衡分侧。

- **上游：** [v1 PRD](../prd-linva-2026-09-24/prd.md) 术语「侧」；搬枝 / 同级排序仍有效
- **体验真源：** `prototype/`（标签 Side）
- **明确不在本增量：** 深层节点独立「侧」属性、导出、主题样式、原生壳视觉打磨

文档语言：中文优先。

---

## 1. 愿景与要完成的工作

自动 `nextSide()` 适合快速建树，但整理时用户常要「这枝必须在左边」。本增量提供**命令入口 + 拖拽手势**两种改侧方式，只作用于**中心主题的直接子节点**（更深节点随所属一级枝所在侧布局）。

---

## 2. 关键用户旅程

**UJ-L1. 阿哲用快捷键把「开放问题」换到右侧。**

1. 选中该一级枝；按 ⌘→ 或点「右侧 →」。  
2. 布局立刻映到中心右侧；子树跟随。

**UJ-L2. 阿哲把左侧一枝拖过中线放到右侧空白。**

1. 拖动一级枝越过画布中线（世界坐标 x=0）；出现中线侧引导。  
2. 在空白处松手 → side 改为 right，仍为中心直接子。

**UJ-L3. 阿哲把某枝拖到中心主题左半。**

1. 落点在中心主题左约 1/3：左侧镶边高亮。  
2. 松手后成为（或保持为）中心直接子且 side=left；若原在更深层级则提升为一级枝。

---

## 3. 术语表（增量）

| 术语 | 定义 |
|------|------|
| **侧（side）** | 仅中心主题直接子拥有的 `left` / `right`；决定辐射方向。 |
| **改侧** | 修改上述 side，或将节点提升为中心直接子并指定 side。 |
| **过中线** | 拖拽时指针世界坐标相对中心 x=0 的左右，用于空白松手改侧。 |

---

## 4. 功能需求

#### FR-L1：命令改侧

- 选中集中至少有一个**中心直接子**时，工具条「← 左侧」「右侧 →」可用。  
- ⌘← / ⌘→（Windows/Linux：Ctrl+方向键）将选中集内所有中心直接子设为对应侧。  
- 非一级枝忽略；多选时只改其中的一级枝。

#### FR-L2：拖到中心主题左右半

- 中心主题水平分区：左约 1/3 → `side-left`；右约 1/3 → `side-right`；中部仍为**成子**（沿用搬枝，侧由 `nextSide` 或既有规则）。  
- `side-left` / `side-right`：将被搬可搬顶层挂到中心下并设定侧（已是一级枝则只改 side）。

#### FR-L3：拖过中线空白松手

- 仅当被拖可搬顶层**全部已是中心直接子**时，空白处可出现改侧意图。  
- 指针世界 x &lt; 0 → 左侧；≥ 0 → 右侧；显示中线引导。  
- 松手只改 side，不改变父节点。  
- 更深节点拖到空白：无改侧意图（仍取消放置）。

#### FR-L4：与成子 / 插同级共存

落在非中心节点上的中部成子、上下边插同级规则不变（见搬枝 / 同级排序 PRD）。改侧意图优先级：有节点命中时按该节点分区；无节点命中时才判空白过中线。

#### FR-L5：视觉反馈

- 中心左右半：根节点左/右镶边高亮。  
- 空白过中线：中线引导 + 「左侧」「右侧」提示。

---

## 5. 非目标

- 为非一级节点存储独立 side  
- 仅键盘或仅拖拽（本增量两者都要）  
- 导出、深色主题、轻填色（另案）  
- 原生菜单文案与快捷键绑定细节（实现时对齐 macOS 菜单）

---

## 6. 验收要点

| # | 场景 | 期望 |
|---|------|------|
| 1 | 选一级枝 ⌘→ | 移到右侧 |
| 2 | 工具条「← 左侧」 | 同上 |
| 3 | 一级枝拖过中线松手空白 | 改侧，仍一级 |
| 4 | 拖到中心左半 | 一级 + left |
| 5 | 拖到中心中部 | 成子（非改侧带） |
| 6 | 深层节点拖空白 | 不改侧 |
| 7 | 多选含一级+深层，点右侧 | 仅一级改侧 |
