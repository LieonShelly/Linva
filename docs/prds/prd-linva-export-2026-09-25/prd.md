# PRD：Linva — 导出（PNG / Markdown）

## 0. 文档目的

本文档描述「结果带出 App」增量：导出 **PNG 整图** 与 **结构化 Markdown**。

- **上游：** [v1 PRD](../prd-linva-2026-09-24/prd.md)
- **体验真源：** `prototype/`（标签 Export）
- **明确不在本增量：** PDF、SVG、XMind/OPML、导入 Markdown、打印对话框精调

文档语言：中文优先。

---

## 1. 愿景与要完成的工作

画布内能力已齐；用户需要把图发到聊天/文档，或把结构拷进笔记。本增量提供两种导出，语义固定：

- **PNG：** 导出前**临时展开全部折叠**，按全树布局绘制整图包围盒（非当前视口截图）。
- **Markdown：** 按树深度生成标题层级（`#` / `##` / …），**忽略折叠**，始终导出整棵逻辑树。

---

## 2. 关键用户旅程

**UJ-E1. 阿哲导出一张全展开 PNG 发到群里。**

1. 点「导出 PNG」；文件下载（文件名取自中心主题）。  
2. 图中含原先折叠枝内的全部节点；导回后画布折叠态不变。

**UJ-E2. 阿哲导出 MD 贴进笔记。**

1. 点「导出 MD」；得到标题大纲：中心 `#`，一级 `##`，依此类推。  
2. 折叠与否不影响 MD 内容完整性。

---

## 3. 术语表（增量）

| 术语 | 定义 |
|------|------|
| **全展开导出** | PNG 布局前将所有 `collapsed` 临时清为 false，导出后恢复。 |
| **标题层级 MD** | 深度 d → `min(d,6)` 个 `#` + 节点文案（多行压成一行）。 |

---

## 4. 功能需求

#### FR-E1：入口

工具条提供「导出 PNG」「导出 MD」。原生实现时应对齐「文件 → 导出」菜单（本原型用工具条验证语义）。

#### FR-E2：Markdown

- 先序遍历整棵树（含折叠子树内节点）。  
- 根深度 1 → `#`；子 +1；深度 &gt; 6 仍用 `######`。  
- 文案：取 `text`，换行压成空格；空文案用「未命名」。  
- 不输出填色 / 侧 / 折叠元数据（纯结构文档）。  
- UTF-8；下载扩展名 `.md`。

#### FR-E3：PNG — 全展开整图

- 导出流程：记录折叠态 → 全部展开 → 布局 → 按包围盒光栅化 → 恢复折叠态（画布 UI 状态不变）。  
- 内容：节点圆角块、连线、文案、**填色**（若有）；不必画分叉 ± 控件与相机 UI。  
- 背景为纸色；分辨率随内容缩放，长边有合理上限（原型约 2400px 量级）。  
- 下载扩展名 `.png`；文件名来自中心主题（非法字符替换）。

#### FR-E4：不改文档

导出不是编辑命令；不入 Undo；不修改 `.linva`。

## 6. 验收要点

| # | 场景 | 期望 |
|---|------|------|
| 1 | 有折叠枝时导 PNG | 图含隐藏子树；导后折叠仍在 |
| 2 | 导 MD | 标题层级与树深一致 |
| 3 | 深树 &gt;6 层 | MD 最深仍为 h6 |
| 4 | 节点有填色 | PNG 可见对应色 |
| 5 | 文件名 | 含中心主题可读名 |
